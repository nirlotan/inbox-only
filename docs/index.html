Install

  1. Get Apple's free TestFlight app.
  2. Come back here and tap Install. TestFlight opens: tap Accept, then Install.
  3. Open Inbox and sign in to Instagram. You stay signed in.

Optional: Instagram in Safari too

  1. Open Settings → Apps → Safari → Extensions → Inbox Only.
  2. Turn on Allow Extension and set instagram.com to Allow.

If it doesn't install

TestFlight says the beta isn't accepting testers: Apple is still reviewing the newest build. That usually takes less than a day, so try again later.

The app stops opening: the build expired. Open TestFlight and install the newest build; with automatic updates on, TestFlight does this for you.
